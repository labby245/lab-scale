**First public release — free and open source.**

- **English and Indonesian**, switchable from the header.
- **Cancel** a running batch at any time; the file in progress is stopped
  immediately and no half-written result is left behind.
- **Disk space check** before frame-by-frame video jobs, with the estimate in
  the log.
- **Optional models on demand:** UltraMix Balanced, UltraSharp and Remacri
  download inside the app when picked (CC BY-NC-SA 4.0, non-commercial use).
- **Update banner** when a newer release is published, and an About dialog
  with the log folder for bug reports.
- Smaller download: about 115 MB on macOS (was ~200 MB).
- macOS: Apple Silicon, macOS 14+. First launch needs one approval in
  System Settings → Privacy & Security → Open Anyway.
- Windows: per-user installer (no admin rights) plus a portable zip.

**Rilis publik pertama — gratis dan open source.**

- **Bahasa Indonesia dan Inggris**, bisa diganti dari header.
- **Batalkan** batch yang sedang jalan kapan saja; file yang sedang diproses
  langsung berhenti dan tidak meninggalkan hasil setengah jadi.
- **Cek ruang disk** sebelum pekerjaan video per-frame, dengan perkiraannya di
  log.
- **Model opsional diunduh saat dipilih:** UltraMix Balanced, UltraSharp, dan
  Remacri (CC BY-NC-SA 4.0, untuk pemakaian non-komersial).
- **Banner pembaruan** saat ada rilis baru, dan dialog Tentang dengan folder
  log untuk laporan masalah.
- Unduhan lebih kecil: sekitar 115 MB di macOS (sebelumnya ~200 MB).
- macOS: Apple Silicon, macOS 14+. Saat pertama dibuka perlu disetujui sekali
  di System Settings → Privacy & Security → Open Anyway.
- Windows: installer per-user (tanpa hak admin) plus zip portable.
