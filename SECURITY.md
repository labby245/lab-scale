# Security

If you find a security problem in LabScale — for example in how it downloads
models or checks for updates — please report it privately by email to
**hello@labstory.id** rather than in a public issue. We will reply and fix it
as quickly as we can.

Kalau kamu menemukan celah keamanan, laporkan secara pribadi lewat email ke
**hello@labstory.id**, jangan lewat issue publik.

Only the latest release receives fixes.
